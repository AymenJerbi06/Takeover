              iPhone sync guide

              Apple Health does not connect to websites directly. An iOS Shortcut can send your daily numbers here:

              1. In Shortcuts, add Find Health Samples for Steps with Start Date set to today.
              2. Add Calculate Statistics and choose Sum.
              3. Add a URL: [Statistics result]
              4. Add Open URLs. Name it “Sync Takeover”.
              5. Optional: schedule it each evening in Automation.

              You can also pass &sleep=7.5 (hours) and &screen=180 (minutes). Enter screen time manually.
