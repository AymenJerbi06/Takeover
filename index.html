          Settings & data

          Sync steps & sleep from your iPhone automatically

          Apple Health has no web API, so a website can't read it directly. An iOS Shortcut can push the numbers here instead:

          1. Shortcuts app → + → add Find Health Samples: Type Steps, Start Date is today.
          2. Add Calculate Statistics → Sum of the Health Samples.
          3. Add URL: [Statistics result]
          4. Add Open URLs. Name it “Sync Takeover”.
          5. Optional: Automation → Time of Day (e.g. 21:00) → run it every night.

          Also supported: &sleep=7.5 (hours) and &screen=180 (minutes). Screen time from Flora / iOS Screen Time can't be read by any app or Shortcut, so type it in at night.
